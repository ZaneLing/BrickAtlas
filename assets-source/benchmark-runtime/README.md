# Runtime collision subset

The archive contains only the collision meshes referenced by the 310 admitted objects and their registered candidates. Mesh hashes, LDraw authors, source headers and per-part licenses are in `manifest.json`.

Credit: original LDraw authors; BrickNet inset conversion by Peter Kulits and Cordelia Schmid. Original license texts are in `assets-source/license/CAreadme.txt`, `CAlicense.txt`, and `CAlicense4.txt`. Repository MIT applies to code only. No fonts are redistributed. The source-backed 3003pe2 repair is identified separately.

Install and verify with `python -m reliability.bootstrap`. No live upstream mesh server is required.
