# 动态主任务：模型全程接管一次拼装

更新：2026-10-28。

**一次动态题就是一个持续运行的积木环境。模型从题目起点接管，直到自己结束或用完预算。** 中途不会重开一道题、替换成预设错误场景，也不会由系统执行参考修复步骤。

## 当前实现的实际情况

| 部分 | 目前是什么 | 应如何理解 |
|---|---|---|
| 底层动态环境 | 接受模型逐步动作；根据实际已装状态选择合法干扰；不强制中间状态符合GT | 已是连续环境，不是每步加载一张静态题。 |
| 参考路线生成与测试 | 脚本按参考安装和修复路线回放 | 证明题目可做，不能证明AI模型已自主完成。 |
| 当前真人GT页面 | 为方便看答案，从第一次事件后的状态展示参考过程 | 是GT检查视图，不是模型实际运行界面，也不是完整模型轨迹。 |
| 新增自主运行入口 | 每个动作都来自同一个模型策略，持续保留对话、动作和反馈 | 用于实际模型全程接管；本轮只做了不付费的运行器检查。 |

因此，现有展示与验证容易让动态题看起来像“正常拼装＋若干静态修复片段”。需要明确区分这种参考回放与模型实际连续运行。

## 谁控制什么

| 决定 | 由谁做 |
|---|---|
| 下一块装什么、装在哪里 | 模型 |
| 什么时候换视角、看零件或说明书 | 模型 |
| 是否有必要撤销已完成的部分 | 模型 |
| 先继续拼，还是先返工 | 模型 |
| 采取什么修法、什么时候回来修 | 模型 |
| 什么时候提交完成 | 模型 |
| 动作是否合法、实际执行后变成什么状态 | 环境 |
| 何时尝试外部干扰、能否合法实施 | 环境，依据模型实际状态 |
| 最后是否满足目标、如何记录事件与失败 | 评估器 |

运行循环为：**给定起点和目标 → 模型决定一个动作 → 环境执行并可能发生干扰 → 返回实际状态 → 同一模型继续决定 → 模型选择结束。**

每步向API返回图像并获得下一次响应，是同一个任务中的交互，不是重新发一题。模型的动作和反馈历史持续保留；不在故障发生后清空上下文，也不临时要求它另答“哪里错了”。

## 模型可以回看历史

新入口提供`inspect_history`，可请求某个已经观察过的步骤。返回图像明确标记为“历史状态”，同时仍提供当前实际图，避免混淆。

历史读图不改变积木、不推进干扰、不重置环境，也会消耗控制器的一次决策预算。过去的图片按需重新提供，避免每轮把所有旧图片重复发送；文字、动作及反馈历史保留。

## 操作范围要说清楚

- **完整物件动态组：** 从空起点开始，物件零件全部可操作；白底板属于环境。新入口默认只接受这一组，并拒绝带脚本前缀的运行。
- **大物件收尾组：** 仍可从预装主体开始，由模型全程完成指定模块。需要明确使用模块模式，单独报告，不能称为整个大物件全件接管。
- “全程自主”指决策控制权。当前统一接口依然使用匿名零件与登记候选位置，不等于开放任意几何编辑。说明书可以按需查看，但不是自动推进的安装脚本。

这保留此前“小物件完整拼、大物件做明确收尾模块”的要求，同时使两组都采用持续模型控制。

## 新入口与运行记录

入口：[run_autonomous.py](../../benchmark/brickplan-repair/bench_design/run_autonomous.py)。它接受一个模型调用适配命令：每轮把含真实PNG内容的多模态请求交给适配器，适配器返回一个动作。模型调用服务、密钥和预算由对应适配器负责；本次没有执行付费模型适配器。

该入口不接收GT动作文件，也不会读取参考动作来选下一步。它记录完整模型请求的哈希、每次模型动作、反馈、历史读图请求和环境运行日志。自主协议有独立输入版本，不能与旧协议的实验结果直接混合。

系统不会因为最终状态看起来正确就自动替模型finish，也不会因为模型失败就补一段GT。模型提前结束会按实际结果判定；格式错、服务错和运行器错误分开记录。

正常／干扰配对仍是评估工具。正式模型配对需要共享模型自己产生的历史，并核对实际请求上下文；脚本回放不能冒充这种实验。

## 本轮验证范围

已通过7项控制器检查，包括：

1. 控制器采用不同于正常参考路线的合法顺序，发生干扰后继续装另一块，再回来修好。
2. 将私有GT动作故意换成不可执行内容，运行仍只执行控制器给出的动作。
3. 回看旧图不会改变当前状态，整段历史不清空。
4. 提前finish、格式错误和服务失败都不会触发自动修复。
5. 运行器观察失败单列为harness error。
6. 不能将收尾模块或已经由脚本拼过的前缀冒充完整自主起点。

另抽查现有D、E7、O三个来源的完整物件入口，均支持空起点、无锁定物件件、全部物件动作句柄可用。该抽查不代表逐题穷举。

**以上使用脚本控制器检查运行器，不是AI模型成绩，也没有证明AI已经完成这些动态题。** 本轮模型API费用为$0。正式实验应使用模型适配器，由模型从头决定全部动作。
