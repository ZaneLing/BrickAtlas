先修测量，再强化叙事

BrickAtlas 当前最危险的不是实验空白，而是公开题目中的表面规律可能让高分绕开目标能力。论文已经诚实声明了不少边界，但仍需用干预实验证明：分数变化来自你想测的证据，而不只是字段、顺序和格式。

投稿建议：大改后再投先把正在运行的旧题集结果标为 pilot；不要立刻将其解释为空间推理或诊断能力。

审稿意见为什么仍然成立

01 / 独特贡献

差异存在，重要性尚未被实证

  • Table 1 主要列“评什么”，没有展示这套接口产生了哪种不可替代的研究结论。
  • 共同实例 ID 是基础设施；只有当它支持可靠的干预与错误定位时，才会上升为研究贡献。
  • 不能仅靠 Related Work 的否定式差异或“首个”措辞补足。
02 / 构念效度

模块分数不自动等于能力测量

  • 论文已经把 V/S/G/E 分开，这是优点。
  • 但字段读取、图运算、动作合法性、视觉识别应分别命名并分别汇报。
  • 共享 ID 不等于单题内完成“视觉定位→结构判断→操作”。
03 / 场景复杂性

原始装配规模尚未成为题目难度

  • 论文已明确 D1–D4 是源规模，不是认知难度。
  • 仍需配对比较完整场景与局部操作数，证明背景会造成干扰、提供线索，或确实无影响。
  • 若无影响，规模应定位为来源与覆盖属性，而非能力难度。

P1 · 构念命名

把任务按直接构念分开

视觉识别、证据读取、图运算、动作合法性、认识论校准分别汇报；Evidence limit 单列，不进综合推理均分。

P2 · 配对干预

证明模型使用了目标证据

同一题上改变关键证据并同步改变答案，同时保持表面格式；检查预测是否随证据变化。
