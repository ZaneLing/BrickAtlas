\section{Reading Guide and Version Boundary}
This supplement documents the display-v3 observation contract,
human qualification, response statistics and graph audit. The full
617 historical question dossiers are distributed separately as
\texttt{dossiers.json} and a searchable HTML interface. They are not
617 new display-v3 questions. Historical prompts and answers remain
historical even when a parent ID is linked to new observations.

This draft adds measurement audits over sealed \texttt{ldraw2-evidence-v3}
inputs; the visual dataset remains \texttt{brickatlas-display-v3}.
Color's 146 endpoints, the 67 panels,
graph inputs and historical dossiers retain their earlier bytes.
A separate parent-mapping overlay supplies current pair IDs; old
dossier links remain in the original JSON. Both primary Part-type
arms are rebuilt. Canonical source identity is the
source hash and placed-instance ID. Display references resolve within
one current image. The complete four-part identity rule and all
parent-to-observation mappings are released with the dataset.
No old model answer or review is transferred to a new prompt.

The artifact has three distinct inspection modes. The evaluator site
exposes pairing, gold and provenance for scientific audit. The blind
review packages expose only one exact observation at a time, without
gold or pair membership. The historical 3D viewer allows rotation,
zoom, source-part isolation, expansion and visibility replay.
Only the blind packages implement the qualification protocol; richer
3D access cannot substitute for judging native model-input pixels.

\section{Exact Visual Stimuli}
\subsection{Reference questions and a concrete pair}
For the OMR 42004 Color example, both arms ask:
\begin{quote}\small
What color is the object currently marked B0035 in this image?
\end{quote}
Both include the rule that references select current image objects and
that appearances or labels may have been edited. Gold changes from
Blue (choice D) to Red (choice C). Original source truth stores Black.
This is an explicit rendered-appearance counterfactual, not a claim
that the source record changed.

For the corresponding Part-type example, both arms ask:
\begin{quote}\small
Which displayed candidate label currently marks an object with the
same visible part geometry as the target marked B0035? Ignore color
and pose. Answer from this image, not from historical source identities.
\end{quote}
Candidate B0036 in A has the same source type, 32250, as the target.
After the B0036/B0116 candidate-reference swap, B0116 selects that
same matching geometry in B. The option-ID gold changes from C to D.
This describes generated golds only. There is no observed model
C-to-D or C-to-C response case in the current release.

Figure~1 in the main paper uses the actual native PNGs with an identical
crop rectangle for the two arms within each family. Its annotations
are paper-only. \texttt{figure-provenance.json} records the four
observation IDs, full PNG hashes and crop rectangles. Full images and
full prompts remain available through the paired-observation inspector.

\subsection{Rendering audit}
All primary and auxiliary images have a native resolution of
1280$\times$800. Color edits keep the geometry, pose, camera, label
projections, visibility and material settings identical. The body mask
is the projected part body; one pixel of dilation accommodates
antialiasing at the silhouette. Changed pixels outside that mask
number zero in every Color pair. The mask test is not a measurement
of human color separability, projected difficulty or assembly stability.

The 73 pairs use two distinct named opaque colors each; both arms
may differ from the historical source appearance. Aggregate category
counts are 37 Red, 37 Blue, 36 Yellow and 36 Black. Canonical color,
part type and transforms are preserved separately. The donor
feasibility inventory retains every candidate considered for the older
mechanism and explains why a general donor swap cannot be relabeled
as a color-only intervention.

Part-type regenerates all 134 primary images after joint option/swap
assignment. Within every pair the underlying geometry render is
byte-identical, with pixel changes confined to label masks.
Two independent regeneration canaries are byte-identical. Source poses,
camera and anchor projections remain fixed. Independent gold validation
reconstructs the display mapping and source part-type equality;
visual uniqueness remains a human judgment.

\subsection{Legal single-image appearance baseline}
All 146 Color endpoints contain one operand and one label. The baseline
does not locate that label: it summarizes connected color regions across
the full PNG. Its only input is one model-visible wire containing the
PNG, system text, question and options. Each prediction runs in a fresh
isolated Python process with an empty working directory. The evaluator
joins IDs and independently derived golds afterward. The predictor
accepts no paths, masks, render specifications, source records or pairs.

The algorithm and thresholds were locally hash-locked after synthetic
tests and before the corpus run. RGB channels are normalized to $[0,1]$.
Pixels with every channel at least .90 are removed as near-white.
Pixels with maximum channel at most .30 vote Black. Other pixels need
saturation at least .35 and hue within $60^\circ$ of the nearest public
prototype (Red $0^\circ$, Blue $240^\circ$, Yellow $60^\circ$).
Within each color, four-connected components smaller than the greater
of 64 pixels and .0005 of image area are removed. Retained areas vote;
the winner needs at least .55 of support, with ties and empty support
yielding abstention. These thresholds are algorithm choices, not
acceptance criteria for the benchmark.

The run gives \EvColorBaselineCorrect/146 correct endpoints,
\EvColorBaselineAbstentions{} abstentions, and
\EvColorBaselineBothHits/73 Both (\EvColorBaselineBothMicro\% micro;
\EvColorBaselineBothSource\% equal-source). Per-observation support
counts, predictions, failures and source intervals are released.
This tests the appearance sanity track, not multi-candidate reference
selection or human answerability. The derived ledgers cover all 347
visual and 219 graph observations; visual qualification remains pending.

\subsection{Position-reference control}
The 67 auxiliary observations each have a target panel and four
candidate panels, without labels inside the image
(Figure~\ref{fig:position}). The question describes which panel is
the target and the ordering of the four candidates. The correct option
is derived independently from source geometry/type correspondence.
No candidate-reference change pair is manufactured from these panels.

Each auxiliary observation requires two independent raw human reviews,
for 134 additional judgments. Its final decidable set and accuracy
are separate from the 280 primary endpoints and their paired Both.
Comparing it with a label-based arm changes several factors at once:
reference interface, separation of objects and view access. A higher
score would not isolate geometry skill, and a lower score would not
isolate position understanding.

\section{Human Review Protocol}
\subsection{Sampling universe and blinding}
Six initial packages contain 115, 116, 114, 115, 115 and 119 units.
Their union covers 146 Color endpoints, 134 Part-type endpoints and
67 position controls exactly twice. Each reviewer sees at most one
observation per parent, including panels. Three-observation parents
use all six people without exposing counterparts. Assignments cross
arm/slot combinations and hide condition names. The validator checks
displayed text/options and image bytes against each frozen wire.

Reviewers work independently before model inference and do not receive
pair membership, condition labels, canonical source records, gold,
model responses or another person's answers. The coordinator distributes
one package to each of six different people. The native image is
scrollable rather than silently downsampled. A reviewer attests that
the full native observation was inspected.

\subsection{Raw and final records}
Every raw record contains:
\begin{itemize}\setlength\itemsep{1pt}
\item opaque unit ID and exact wire-observation hash;
\item reviewer pseudonym, timestamp and independence attestation;
\item decidable, ambiguous, unanswerable or contradictory decision;
\item chosen visual option where applicable;
\item four Boolean reference/answer/visibility/contradiction checks;
\item reason code, free-text reason and native-size attestation.
\end{itemize}
A decidable record requires a listed option, all four checks passing,
and the no-exclusion reason code. Nondecidable records require a
reason. Raw records are never overwritten by a final decision.
Duplicate raw reviews, reuse of a reviewer identity across the six
slots, obsolete hashes and synthetic evidence are rejected.

If categorical decisions, choices and checks agree, the record is
finalized under the frozen rule. Different explanatory prose alone
does not constitute a categorical disagreement. Any decision, choice
or check disagreement requires an additional person's adjudication.
The adjudicator sees the single observation and the two judgments,
but not gold, the other endpoint or model responses. A reason is
required. Up to three extra adjudicator slots receive disjoint parents;
they cannot be initial reviewers or see any other view of a parent.
Final import reconstructs decisions from retained original exports.
A final decidable choice conflicting with the generated
gold returns the item to pending and requires dataset revision.

\subsection{Agreement and gate semantics}
For doubly reviewed units, raw decision agreement is the fraction
of equal categorical decisions. Descriptive pooled two-slot kappa is
\begin{equation}
\kappa=(p_o-p_e)/(1-p_e),
\end{equation}
where $p_e$ is computed from the two empirical decision marginals.
Assigned people vary across units; this is not the reliability
coefficient of one fixed pair of reviewers.
No doubly reviewed units yields null; degenerate marginals with
$p_e=1$ also yield null. Choice agreement and each structured check
have separate statistics. Primary and auxiliary counts are explicit.
Adjudicated agreement does not replace raw agreement.

Before real inference, every planned endpoint needs a final nonpending
decision. This gate does not require every endpoint to be decidable:
ambiguous, unanswerable and contradictory outcomes remain part of
the full benchmark report. Additional QA-subset estimates require
both endpoints to be finally decidable. Missing either A or B blocks
that pair's inclusion. The final summary is reconstructed from retained
raw inputs; editing a summary cannot satisfy the gate.

At release, raw human reviews are 0/560 for primary endpoints and
0/134 for auxiliary controls. Final primary decisions are 0/280;
both-decidable pairs are 0/140. These are unresolved acceptance
requirements. Software tests exercise the rule with temporary
synthetic fixtures; none is imported as a real review.

\section{Statistics and Genuine Response Evidence}
\subsection{Outcomes and denominators}
For a changed-answer pair, B outcomes are mutually exclusive:
correct new answer, valid old answer, another valid answer, or invalid.
Their micro proportions sum to one over all planned pairs.
A accuracy and Both additionally distinguish the A endpoint.
Missing calls do not remove the pair. JSON validity is reported for
each arm and for both, not inferred from semantic correctness alone.

Conditional adaptation uses only A-correct pairs. Micro adaptation is
the both-correct count divided by that count. Source-macro adaptation
first computes each source's conditional rate, then averages over
sources with at least one A-correct pair. The report includes both
eligible pair and eligible source counts. Those two estimands can
differ; neither replaces unconditional Both.

For invariance graph pairs, $y_A=y_B$. Both remains the joint success
criterion. A repeated wrong answer is consistent but incorrect.
Stability of raw invalid strings has no semantic meaning. The current
visual release does not import older camera/ID-renaming invariance
responses under the new display contract.

\subsection{Sources, subset shifts and rank comparisons}
Source-macro estimates give equal weight to sources after averaging
their within-family pairs. Whole-source resampling uses 10,000 draws
and a fixed seed, 20260920. Paired model differences use the same
items and resampling weights. The QA-minus-full calculation recomputes
both means using shared source draws and the subset's actual source
coverage. A draw containing no eligible subset source is recorded
as undefined; it is not assigned a zero score.

Rank points are computed using exact rational source means. Equal
values receive midranks, avoiding arbitrary floating-point thresholds
for ties. The rank comparison reports A, NewAcc and Both, the sign
of each paired difference, point reversals versus ties, descriptive
intervals and agreement of directions across full/QA sets. With many
families or models, these unadjusted comparisons remain exploratory.
An interval containing zero supports neither directional ranking nor
equivalence. The estimand is a single complete invocation set; no
interval here measures cross-call provider variability.

\subsection{Response cases and authenticity boundary}
Only the exact roster of nine terminal live runs can enter empirical
analysis, including explicitly closed failures. All visual/no-image runs
share one finalized QA snapshot. Run IDs, adapter files/hashes, inclusion
reasons and requested/expected revisions are frozen. Missing or extra
runs block analysis; changing a model requires a new study version.
The runner records raw response bytes, extracted output
text, normalized choice, model revision and full-request hash. Analysis
reparses raw responses; it does not trust manually entered accuracy
columns. Missing or malformed responses remain failures. Requests and
intents precede network calls. Interruption closure distinguishes unattempted
requests from attempted calls without receipts; both remain in the 2,739
scheduled denominator. Closure records are not provider responses.
The model-run index binds each roster entry, requests, receipts, QA,
run dates and report rows. Current completed/planned runs are 0/9.

The no-image control removes only image content from all 347 visual
messages per model. All 140 primary pairs have byte-identical stripped
requests and different golds. Identical deterministic predictions imply
Both=0 and symmetric endpoint accuracy at most $1/2$. Temperature zero
does not establish provider determinism. This is an image-content floor,
not a reference-selection floor; image-minus-no-image alone cannot
demonstrate reference following. Graph scores remain separate.

Case extraction uses genuine QA-decidable pairs, separately by family
and model. It looks for A-correct to new gold, A-correct to old gold,
and the same valid wrong answer at both endpoints. Selection is
deterministic by hash order within a case type. An absent type stays
absent, and its absence is not filled with a constructed response.
At release there are no eligible real cases and no empirical rank
comparison. The example in Section~2 describes stimulus semantics only.

The collection pipeline checks hashes, provenance and declared
response models. Local files and attestations alone cannot
cryptographically prove that a remote provider generated a receipt
or that two humans worked independently. Retained provider records
and coordinator oversight complement the machine checks.

\subsection{Answer balance and small-sample limits}
The strong direction count is six increases and six decreases.
Table~\ref{tab:balance} discloses that raw arm answer frequencies
are not identical. Both is invariant to swapping endpoint roles.
Symmetric endpoint accuracy averages the two endpoints within
each existing pair. Optional equal arm weighting uses each endpoint
in both arm roles with half weight; it changes neither observations
nor pair/source counts. It does not create uniform label frequencies.

The Wilson intervals [0, .2425] and [.7575, 1] for 0/12 and 12/12

Boundary whole-source bootstraps may collapse to a point. The

All strong graphs instantiate a narrow construction: six-cycle
versus two triangles, plus identical isolates. Uniform-feature
anonymous 1-WL cannot distinguish them at any refinement depth.

more aggressively. A model with unique-ID features, positions,
spectral information or higher-order computation is outside this
feature restriction. No trained GNN or language-model result is
claimed by the algorithmic audit.

\section{Source Coverage and Historical Controls}
Table~\ref{tab:sources} makes source coverage explicit. Source files
come with recorded URLs, author attribution, license metadata and
content hashes in the historical catalog. Dataset-level paired
analysis cannot substitute for source-level split discipline.
Any future training/evaluation split must keep each source and all
its derived views, interventions and controls together. Common part
libraries may still create dependencies across such splits.

The historical families remain an inspection resource. Distance
reads coordinates and computes a value; Interface and Coverage
read supplied records; Step lookup reads author annotations.
Neighbors and Graph deletion operate the explicitly supplied graph.
Evidence limit and Step sequence include fixed-answer controls.
Restoration follows a visibility contract at a saved source pose.
None establishes physical insertion planning.

The viewer can replay these actions, expose the original graph/records
and inspect part IDs. Expansion is an inspection transformation,
not a physically valid final arrangement. Isolation omits supports
without changing the saved assembly. Source-local overlap candidates
still require physical review. The new color and label interventions
do not claim to have corrected the historical source geometry.

\section{Reproduction and Acceptance Checklist}
The source package contains this manuscript, its main paper, generated
tables, figures, bibliography and the CVPR style. Both PDFs compile
with Tectonic. The repository additionally contains the publication
generator, frozen stimuli, review packages, validators and raw-input
hashes. The build guide specifies the checked runtime and commands.

The following machine checks are complete in this release:
347 frozen native visual observations; 140 paired gold changes;
73 controlled body-pixel differences; all visual golds independently
recomputed; 219 graph request snapshots and dual-algorithm gold checks;
all 2,739 planned request envelopes; and 27 new protocol/analysis tests.
The 26 historical tests remain preserved. Browser and PDF inspection
validate delivery behavior and layout. Those inspections are not
human visual-task certification.

Empirical acceptance remains open for the 560 primary human reviews,
134 auxiliary reviews and any necessary adjudications, followed by
new model inference. The required analysis must show full and
QA-decidable results, valid-format rates, family-specific response
transitions, paired source intervals and genuine case examples where
they exist. If the findings fail to reveal added diagnostic value,
the claims must contract accordingly. No receipt-free score,
invented rank reversal or synthetic human judgment can close these
requirements.
