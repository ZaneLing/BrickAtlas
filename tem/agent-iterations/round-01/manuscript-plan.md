# 论文整合范围

主 agent 负责当前论文和表格；研究 agent 负责新版本 benchmark，不交叉写文件。

## 主线

以“视觉绑定如何影响组合修复”作为统一问题，保留 CAD 来源和独立 GT 优势。
颜色与原始标签交换降为历史诊断，不借旧实验量宣称新任务规模。
源图、原始坐标和实例 ID 只用于明确许可的条件；新任务需图像与结构共同决定答案。

正文拟包括：

1. 问题与贡献：同一个结构问题中分别检验视觉绑定和最优修复，允许实验无差异。
2. 相关工作：按输入、必需操作、变化/保持控制与 GT 证书对比。
3. 新任务合同：公共输入、输出、构造单位、图与图像依赖。
4. 构建与控制：去重与划分、选择台账、变化/保持、浅层捷径、资格审核。
5. 评价与实验：语义评分、共享父项与组级统计、模型类、主结果及分解空表。
6. 局限与发布：有限源集合、抽象连接语义、未认证的物理能力和实际采集状态。

## 图和表

- 正文图必须展示新版本中实际存在的输入、题目、必要视觉证据及完整 GT。
- 保留真实积木渲染和复杂约束，不用旧三例作为新主任务的替身。
- 正文最多保留紧凑模型类别/主结果/条件分解表；
  完整模型参数、次要矩阵、逐题证书和历史工作量移入附录。
- 所有未测数值保持 null/空单元格；算法审计单列。
- 不改 CVPR 样式，不缩小字体绕过页数；自动验证正文不超过 8 页。

最终公式、条件名、数量、采样分母和主图只从新版本已生成产物读取，
不预填研究 agent 尚未实现的承诺。
