## 本地性能基线

`assets-built/performance-report.json` 保存 7 次生产构建冷浏览器上下文的采样数据。环境：本机 macOS arm64、headless Chrome、1440×900、localhost。

- 初始绘制调用：123。
- 动画实测约 60 FPS。
- JS heap 约 40 MB；不是整个 GPU 或浏览器进程内存。
- 首块几何就绪 P50 约 74 ms，P95 约 124 ms。
- 全部几何解码就绪 P50 约 122 ms，P95 约 171 ms。
- 渲染调用耗时 P50 约 3.9 ms，P95 约 4.6 ms。

这些时间从场景初始化起计，不包含生产 DNS、网络 RTT 或真实首屏绘制时间；不能作为公网性能承诺。脚本可通过 `npm run benchmark` 重跑，具体数字以最新 JSON 为准。

## 已披露限制

- 31009、10156 使用 OMR 作者 STEP；其余模型的步骤明确标注为结构演示，不推断为官方说明书。
- manifest 实例数不宣称等于包装库存、备用件或同套装其他搭建形态。
- 六个功能组为编辑规则。原始七个子模型的身份和路径全部保留。
- 完全陈列是非重叠布局，不是精确机械碰撞拆装模拟。
- 数百零件同时陈列时需缩放、搜索或分组隔离；没有把全部几何强行放大并保持全屏可见。
- 当前压缩为 gzip、Float32 几何，不采用有损 LOD。该规模的实测不支持提前引入减面。
- 逐实例拾取网格保留原始三角形，先做包围盒粗筛；千级高复杂模型应再次实测 BVH/LOD 的收益。
