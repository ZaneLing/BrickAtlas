## 3. 指标的关键纠正

| 问题 | 现在怎么写 |
|---|---|
| 静态只看最后对错，掩盖越修越坏 | SR/F1/ER/DR一起报；S0另算误修FR。 |
| 把完整大背景都算正确零件 | 只计可操作的目标范围。 |
| 逐步不符合GT就判错 | 最终物理状态正确即可，允许合法不同顺序。 |
| 未到事故就说修复失败 | 列未触发／部分触发；不进合格恢复分母。 |
| 正常不会拼也算修复能力差 | CRR要求相同前半段的正常对照成功。 |
| 事故反而帮模型拆掉了错件 | 核实实际事故效果，再决定能否计恢复。 |
| 正常失败的配对全被排除 | CRR筛正常成功；ΔSR保留所有技术合格配对，两者分母不同。 |
| 修复必须回到旧中途图 | 只恢复该事故破坏的正确位置、清除其新增错误，允许继续正确施工。 |
| 服务错误、格式错误混作能力差 | 终止服务错误另列；格式、字段、物理拒绝分别记录。 |
| 一次短暂429就整局作废 | 原决策重试后完成仍可有效，重试费用保留。 |
| 把参考路线叫最优 | 明说可行路线，动作比可小于1，不叫SPL。 |
