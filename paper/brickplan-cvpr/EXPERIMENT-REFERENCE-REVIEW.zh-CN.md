# 实验设计与已有工作的关系

更新：2026-10-25。当前设计和19张结果表见[实验计划](EXPERIMENT-PLAN.zh-CN.md)。文献条目在`references.bib`，正文／补充材料保留原有引用；本轮没有重新做一轮文献搜索。

| 参考方向 | 我们借鉴什么 | 不可以直接照搬什么 |
|---|---|---|
| LEGO-Puzzles、PhyBlock | 分任务、分复杂度、真人对照、部分零件质量 | 它们的任务规模或得分不能当作我们的成绩。 |
| Break and Make | 结构重建、完全完成以外的质量 | 输入、配准和动作空间与我们不同。 |
| SCANet | 原错误改善与新增损坏分开 | 我们按可操作部分的物理多重集合，公式以当前规范为准。 |
| AsgardBench | 历史图、视图、反馈等输入因素分别对照 | 加显式文字状态可能多给遮挡信息，不能说完全等信息。 |
| RoboRecover | 偏离状态后的继续、阶段、跨模型恢复 | 不能借其真实机器人条件替我们证明物理真实性。 |
| BrickBench | 合法性、目标质量、人工判断、成本分开 | 开放设计与固定目标拼装不同，不能把分数直接横比。 |

当前论文新增的具体约束是：GT顺序不唯一、正确终态按物理等价、当前画面与目标统一、正常对照成功与事故触发／效果核实、重复事件窗口、服务／格式失败分开。未实现或未测的分析留空。
