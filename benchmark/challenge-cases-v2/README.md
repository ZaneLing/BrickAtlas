# BrickAtlas Challenge Cases

Six original 49-63 part structures and twelve advanced task contracts. This layer stresses long-horizon recovery, counterfactual support, compound editing, multi-fault repair, active inspection, graph reasoning, distributed completion, module transforms, next-step selection, pose estimation, large-scene reconstruction, and inventory-constrained redesign.

No model scores have been run on this layer. See `../CHALLENGE_REPORT.zh-CN.md`, `CONTACT_SHEET.png`, and `TASK_MATRIX.png`.
