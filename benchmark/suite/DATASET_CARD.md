# BrickAtlas Multitask 数据卡

## 发行身份

- 版本：brickatlas-multitask-1.0。
- 数据性质：程序化公开开发集，不是论文级私有测试集。
- 552 个结构样本；138 个去颜色、平移和四向旋转规范化的几何组；8 个参数化结构族。
- 每个基础模型派生8种任务，共4,416个绝对表示任务。相对表示是同一道题的另一种编码，不增加独立样本数。
- 25 个规则砖/板目录项，使用真实 part ID 和标准名义尺寸；渲染为程序化近似，不包含精细管道、底面、印刷和材质缺陷。
- 结构族：bridge、bench、shelf、wall、tower、platform、staircase、gate。
- 宽度4/6/8 studs，深度2/4 studs，高度参数1/2/3，四组配色。去重后不是完整笛卡尔积。
- 当前没有人工创建或网络采集的新模型进入计分数据。本地15个OMR模型仅作只读来源/许可盘点。

## 来源与许可

程序化生成的布局数据以 CC0-1.0 释出。代码遵循仓库许可；第三方依赖保留各自许可。
零件号与名义尺寸不等于 LEGO 品牌授权，不声明得到品牌认可。
OMR盘点不更改、不重新授权源模型；后续引入第三方结构必须逐项保留作者、来源、许可与原始哈希。
运行 `suite:prepare` 生成 `artifacts/omr-audit.json`。

## Schema

每条 ModelRecord 包括 id、group、family、split、description、parameters、
structure（version/parts）、connections（砖间连接及交叠stud数量）和provenance。
位置 x/z 以stud为单位，y以plate为单位，锚点为砖体最小角，turn=0/1/2/3。
模型在首次生成时必须满足：

1. 目录、颜色、坐标与ID有效。
2. 无矩形体相交。
3. 每个非地面零件至少有一个下方支持stud。
4. 所附顺序可从空场经由无阻挡垂直插入完成。

“至少一个支持stud”不证明受力稳定。这些是离散几何规则，不是机器人或扣合力模拟。

## 划分

| split | 样本 | 派生任务 |
| --- | ---: | ---: |
| train | 296 | 2368 |
| validation | 40 | 320 |
| test_id | 96 | 768 |
| test_ood | 120 | 960 |

六类常规结构按规范化几何组哈希分桶；staircase和gate整族作为test_ood。
同一几何的配色变体、所有图片和派生任务继承相同split。程序自动拒绝跨split的相同几何组。
OOD表示本生成器内留出结构族，不等同未知现实世界类别或零件类型。
所有split共享公开零件词汇。零件识别任务可能在不同父结构中重复同一目录零件/颜色；
因此该子任务仅为已知词汇识别回归，不能当作未见零件泛化证据。

## 图像与可观测性

- RGB 640x480，Three.js生成，非照片。
- parts：孤立零件的斜视和俯视。
- reconstruct/complete/repair：组装斜视图 + 按底部y逐层取出的俯视图。
- 逐层图像明确披露层高，降低闭壳遮挡的不确定性；模型未获得各零件坐标。
- 相同层内名义几何与颜色可见；输入BOM提供型号统计。不是RGB-only无目录重建。
- 自动相机缩放、灯光、背景是固定渲染协议的一部分。不要把此任务成绩等同真实照片重建。

## 多任务边界

generate 是文字加空间体积约束，不是自由文本审美生成；允许不同目录铺砌。
edit覆盖改色、指定零件顶部复制和删件，不是任意自然语言语义编辑。
repair包含错误颜色、x偏移、额外零件和无故障；参考目标按图像提供，原结构按程序提供。
plan只要求垂直插入/移除，无连续SE(3)、铰链、轴、夹具和机械臂。

## 规模与泛化风险

552样本来自138几何组及8模板。组内、族内样本相关，不能用4,416任务假装4,416独立现实对象。
自动描述是模板化生成，不声明高质量自然语言语义覆盖。
几何组去重不等于拓扑族去重；ID测试仍是模板内插值。
数据生成程序公开，属于可复现开发集。私有种子不足以阻止对生成器的过拟合；
未来正式benchmark需要保留新模板/人工设计/新组合并审计污染。

## 导出

`suite:prepare` 把模型和train/validation的SFT配方写入忽略的 `.runtime/suite-exports/`。
训练配方的 `renderRequests` 是可信数据预处理输入，不可直接当作被测模型的视觉输入。
`suite:export` 先渲染图像，再输出不含目标几何的 `inputs.jsonl` 与PNG，用于外部模型。
发布的 artifacts 包含manifest、各族实例、baseline统计和来源盘点，可用生成器复现完整数据。
