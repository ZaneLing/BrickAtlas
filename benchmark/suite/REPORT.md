# BrickAtlas Multitask Suite：第一版交付与实测

## 交付定位

完成了独立多任务工程版本：结构数据生成、分组划分、八任务协议、两种结构编码、
确定性评分、外部模型输入/输出接口、OpenRouter实测、结果回放、训练配方导出和网页。
不包含机器人、机械手、VLA。旧CARE-mini保持原样，新套件默认 http://127.0.0.1:5175。

本次交付不等于已经达到BrickNet级别的数据规模、连接器覆盖或训练实验深度。
明确未完成的研究级事项在本报告末尾列出，不能将工程验收替代论文实验。

## 数据与任务

- 552个程序化结构样本，138个规范化几何组，8个结构族。
- 25类标准矩形砖/薄板目录；布局参数变化与颜色变化分开统计。
- 八类任务，共4,416实例：零件、关系、重建、生成、补全、编辑、规划、修复。
- train 296结构、validation 40、test_id 96、test_ood 120；所有派生任务继承几何组split。
- 2,368条train和320条validation的SFT配方已导出，未将测试答案混入训练配方。
- 15个既有OMR模型已只读盘点并保留许可；未伪称为具有通用连接器真值的计分数据。
- 所有目标有符合本离散规则的装配序列；4,416个oracle测试全部通过。

## 实际测试对象

主要测通用LLM/MLLM，不测机器人策略：

1. one-shot绝对结构：两个模型，各16题，32次推理。
2. validator-once绝对结构：同两个模型、同16题，各题增加恰好一次合法性反馈，64次推理。
3. one-shot相对结构：Gemini的关系、编辑、规划三类，各2题，6次推理。

共70个计分case、102次真实OpenRouter请求，所有请求正常结束。
模式2是工具辅助流程，不是裸模型成绩；模式3只覆盖三类，未测任务不计分。
没有按结果更换题目、改答案、隐藏失败或自动重试。

## 主榜结果

每单元n=2，一例test_id、一例test_ood。此规模用于验证整个流程，不能支持可靠排名。

| 任务 | GPT-4.1 mini | Gemini 2.5 Flash |
| --- | ---: | ---: |
| 零件与接口 | 0/2 | 2/2 |
| 空间与连接关系 | 1/2 | 2/2 |
| 多视图重建 | 1/2 | 1/2 |
| 条件生成 | 0/2 | 0/2 |
| 结构补全 | 2/2 | 2/2 |
| 指令编辑 | 2/2 | 2/2 |
| 装拆规划 | 2/2 | 2/2 |
| 错误修复与定位 | 2/2 | 1/2 |
| 此次选定16题合计 | 10/16 (62.5%) | 12/16 (75.0%) |

成功必须满足任务的全部约束。修复只把几何修好但没有正确指出输入错误ID，仍不能拿满分。
重建输入含明确披露的逐层俯视图，不是凭单张照片恢复不可见结构。
生成输入是受控文字+体积约束，不是开放式文字审美设计。

## 辅助榜与表示检查

| 条件 | GPT-4.1 mini | Gemini 2.5 Flash |
| --- | ---: | ---: |
| one-shot / absolute / 16题 | 10/16 | 12/16 |
| validator-once / absolute / 同16题 | 8/16 | 12/16 |
| one-shot / relative / 关系编辑规划6题 | 未测 | 6/6 |

一次合法性反馈没有在这批小样本上产生总体提升。不能从这点推导“反馈无用”：
合法性反馈不告诉模型目标位姿，而部分失败恰恰是几何目标不符或关系判断错误。
辅助榜重新调用模型，第一轮采样也不与主榜逐token锁定，因此不是严格因果消融。
相对表示的6/6只证明该表示的运行路径可用，不证明优于绝对表示。

## 验证证据

- 新多任务测试23组，包含全量4,416 oracle、相对表示往返、跨split几何组检查。
- 旧模块25项核心测试与新23组共48项通过；原项目69项单元测试另行回归。
- 浏览器8项检查：桌面1440x1000、手机390x844、真实三维非空及旋转、
  八类API提交、图片加载、原始结果浏览、文件隔离、无自动收费。
- 三轮实测的全部70个case可从原始响应重新解析、重算分数，源码/选择/数据/图片哈希核验通过。
- 外部JSONL入口已用16条真实模型答案独立复算一致；缺失答案被计失败而不是从分母删掉。
- train/validation导出验证没有跨split几何组，外部测试输入文件不包含私有render几何。
- 类型检查和独立前端生产构建通过；没有修改原项目src或模型资产。

## 可继续开展的研究

1. **数据规模与质量**：拓展不同结构机制、人工设计模型和长尾零件，而非只增加配色。
2. **更丰富几何表示**：引入真正类型化连接器和非网格姿态，保留可靠连接真值与合法性判断。
3. **真正训练实验**：当前只有通用模型API基线与SFT配方；未训练统一神经模型，
   未做单任务/多任务训练、模型规模或数据规模消融。
4. **更广生成与编辑**：自由文本语义、几何尺寸改造、子装配替换目前不属于已验证任务范围。
5. **更强实验设计**：增加独立结构族、人工审计、多个重复试验、按族统计，
   正式模型测试集不与公开开发练习混用。

这些方向均不需要机械手或机器人。工程版本已经可评测，但研究级完成不能仅通过多跑现有模板宣称。
