# BrickAtlas Casebank v2 中文研究与验收报告

日期：2026-09-12。范围仅 `benchmark/`，无机器人、机械手或 VLA。

## 一、目前做到什么程度

当前交付已从“少量模型 smoke test”扩展为**带逐题 ground truth 的可运行评测数据资源**：

- **5,120 个独立几何结构**，每个结构 9–47 件；不是配色扩充出来的数量。
- **66,710 个任务变体**：每结构 13 个变体，另有150个独立目录识别题。
- **117,910 个任务条件 case**：每结构23个输入条件实例，另有150个目录题。
- 每题实际保存 ground truth、公开输入、私有渲染配方、适用指标、oracle评分和内容hash。
- 全题库运行了**仅读取公开输入的传统算法基线**，保存所有输出、分层统计和可复算回放。
- 全量真值/输入/渲染配方重新生成比对通过；无原runtime、无API密钥的副本复现通过。
- 新增 Casebank v2 页面，支持分页筛选、显式裁判真值、逐项评分、全部基线输出和回放。

**这不是117,910次大模型调用，也不是117,910个独立对象。**
本轮没有增加付费模型请求；新版尚未完成大规模神经模型评测。
论文定位应是“可审计多任务casebank及当前验证结果”，不能写成已经证明超越前人的完整研究。

## 二、数据规模与划分

| 划分 | 独立结构 | 任务条件case |
| --- | ---: | ---: |
| train | 2,690 | 61,870 |
| validation | 392 | 9,016 |
| test_id | 758 | 17,584 |
| test_ood | 1,280 | 29,440 |
| 合计 | **5,120** | **117,910** |

test_id 的case数额外包含150道已知目录题：25种零件×6颜色。
同一种目录零件的六种颜色共享统计group，不当作六个未见零件类型。

八种生成策略各640个结构：

1. `tip-walk`：沿当前端点生长，单支撑父节点。
2. `low-fan`：低层父节点扇出。
3. `shallow-terrace`：更严格的低高度附着。
4. `plate-network`：薄板连接网络。
5. `column-field`：公共底板上的独立高度柱列。
6. `alternating-beams`：相邻梁的朝向交替。
7. `two-support-bridge`：先建两侧支撑，再放跨梁。
8. `enclosed-shell`：外围墙体、内部布局和封闭顶盖。

前六策略按几何hash划分train/validation/test_id；桥梁和封闭外壳策略全部留出。
这是**生成策略留出**，不等于证明训练数据没有相同原语或语义子结构。
所有结构都使用同一规格根底板，这也是明显的数据多样性限制。

去重使用无颜色、平移和四向yaw规范化的完整零件几何；同时排除与两个历史版本的精确重复。
镜像不并入等价类。按完整对象先分组，所有派生任务继承同一split。
近重复额外做32个hash、8个band的LSH筛查，48个跨split候选中没有Jaccard≥0.8的标记对；
这不是穷举检查，不能声称不存在近重复、子装配复用或预训练污染。

小/中/大三档按件数划分，分别1,445/2,141/1,534个结构，不是人类难度标签。
14个压缩数据分片总计约69 MB，随项目提供；无需调用API重建答案。

## 三、每个case的ground truth

`ground-truth-{split}.jsonl.gz` 是实际逐题数据，不只是生成脚本。

| 真值内容 | 用途 |
| --- | --- |
| case ID、对象group、split、输入hash | 锁定题目版本与派生关系 |
| `answerSemantics` | 区分唯一字段答案、对称结构、多解可见面、多解计划、约束见证 |
| `oracle` | 一个已验证的答案；多解任务不是强制唯一答案 |
| `target/source` | 目标结构与已有结构 |
| BOM、尺寸、连接边、每个名义stud对接点 | 部件、几何与连接评价 |
| `changedIds/preservedIds` | 修改/故障区域与必须保持的区域 |
| 每种零件的yaw对称群 | 同型号等价朝向处理 |
| 装配/拆卸顺序见证 | 证明存在可执行顺序，但不替模型修复错误顺序 |
| 独立整数体素checker证据 | 与主几何检查器交叉核对 |
| 指标列表和oracle各项评分 | 每题具备明确evaluation合同 |
| 标注来源与humanReviewed=false | 不把程序标注冒充真人审核 |

**公开输入文件不包含spec中的故障类型、changed IDs、oracle或裁判渲染几何。**
外部导出只发 `caseId/system/input/images`。完整case index和GT文件虽然公开用于研究，
但禁止作为视觉题模型输入。当前是公开开发集，不是防作弊私有榜。

## 四、八任务与指标

| 任务 | 覆盖变体 | 核心评价 |
| --- | --- | --- |
| parts | 型号×颜色 | 型号、颜色、stud数、字段准确率 |
| relations | 连接/非连接查询 | 直接连接、上下关系、stud数、最短图路径 |
| reconstruct | 普通/分层/符号 | 部件/BOM/连接、占用IoU、有色IoU、表面与完整结构成功 |
| generate | 多解硬约束生成 | 尺寸、原点、件数、颜色数、连通分量、分支度、合法性 |
| complete | 移除末段后的补全 | 重建指标、原结构保持率、增件P/R/F1 |
| edit | 旋转/改色/删件 | 完整目标、修改效果、非目标保持 |
| plan | 装配/拆解 | 原顺序执行、合法前缀、执行覆盖、提交覆盖、长度、重复ID |
| repair | 正常/错色/偏移×三条件 | 结构恢复、定位P/R/F1、保持、正常样本误报 |

具体公式、空集合约定和每项主判据见 [METRICS.md](METRICS.md)。

重要边界：

- 普通RGB允许相同正X/Y/Z有色first-hit表面及BOM的不同隐藏布局；同时要求合法性、保持和定位。
- 分层图及完整符号信息条件要求完整结构正确；不将不同信息量混榜。
- 表面指标是名义网格代理，不是像素相似度或完整透视可见性证明。
- 相同型号/颜色/位置的零件ID可互换；方形零件和矩形零件分别处理四向和180度yaw对称。
- 生成评价公共约束，不按任一参考方案的Part-F1判输赢。
- 计划按原提交顺序执行；不得由系统重新排序后补记模型成功。
- 漏答保留分母。格式错误不能成功；QA仍可保留正确字段的部分分。
- null只表示不适用，如有故障样本的“正常样本误报率”，不用于隐藏失败。
- 聚合按任务/变体/条件/split，并提供策略与件数分档；每指标附分母。
- bootstrap以对象group为单位，1,000次、固定seed731；不是把所有派生题当独立样本。

## 五、全量evaluation实际结果

传统基线只接收PublicTask，不接收CaseTask/GT。
它实现符号关系计算、指令编辑、贪心装拆和符号参考比对；不具备视觉识别或约束生成求解器。
不支持的题型返回空答案并记0，解释上应标“能力未覆盖”，不能冒充视觉模型失败。

| 可执行功能 | 成功数 |
| --- | ---: |
| 符号关系（两个查询变体） | 10,240/10,240 |
| 符号编辑（三个变体） | 15,360/15,360 |
| 特权符号重建/补全/三种修复 | 25,600/25,600 |
| 贪心装配 | **2,364/5,120（46.2%）** |
| 贪心拆解 | **5,120/5,120（100%）** |

装配细分：

| split | 成功 |
| --- | ---: |
| train | 1,615/2,690（60.0%） |
| validation | 230/392（58.7%） |
| test_id | 468/758（61.7%） |
| test_ood | 51/1,280（4.0%） |

这是**固定算法的难度对比**，不是学习模型的OOD泛化结论。
反例说明：当前放置合法并不保证未来可装；贪心先放桥梁或顶盖可堵住下方待放零件的垂直通道。
它不说明搜索算法、依赖图规划器或模型必然同样失败。

开发阶段还发现并修正两项影响有效性的缺陷：

1. 30道偏移修复题可能与另一同型同色零件位置重合，故障ID不可辨识；生成器已排除并全量重建。
2. 初始公开输入旁附带了裁判spec，其中包含故障变体；已移除并重建、复验所有公开输入。

两个预冻结结果保留在本地runtime，不作为最终发布实验。

## 六、神经模型与训练目前的证据

神经实验仍来自历史数据版本，不能标成v2全量结果：

- composition-v1：两模型各56题，共112请求，实际只有4个共同对象。
- 普通RGB和分层条件，两模型重建/补全都是0/4；特权符号条件都是4/4。
- Gemini同首答控制：首答、纯反思、一次合法性反馈均2/12，没有新增成功或退化。
- Grid-v1本地Qwen3-0.6B：base 0/8、single 2/8、multi三个seed分别1/8、1/8、2/8。
- 四套真实LoRA权重、480优化步与40条预测保留；所有成功均来自edit，没有广泛迁移证据。
- 本地训练是文本/结构，不是多模态；匹配步数但不匹配token预算，不是严格迁移因果对照。

此前246例模型结果仍可回放。新117,910例是传统算法输出，不是新增大模型推理。

## 九、尚未完成的研究目标

- 真正独立人工审核仍0条；审核界面和程序checker不能代替真人参与。
- v2神经模型大样本实验、多模型家族比较尚未完成。

本轮已经完整落实的是：**扩规模、逐题GT、逐项evaluation、全部传统基线结果、可审计复现与说明文稿**。
