\section{Version and Scope}
This supplement accompanies the LDraw-1 replacement release:
\LDrawSources{} original sources, \LDrawParts{} part instances and
\LDrawTasks{} tasks. It contains source attribution, actual four-view
renders, numbered example inputs, all English question prompts and
reference outputs. Full options and public evidence tables are provided
in the versioned JSON. No old synthetic model, physical pass or model
pilot is pooled into these counts.

The original MPD files, colors, poses and dependency geometry are
preserved. Temporary visibility edits apply only to a display copy.
All source candidates and exclusion reasons appear in
\texttt{benchmark/ldraw-v1/release.json}. Per-source audits retain
unsupported instances and intersection candidates. The release is
intended for review; it does not certify physical stability.

\section{How to Read the Task Contracts}
A displayed number such as \texttt{B0001} identifies one source
instance. The same number appears in the task, interactive view and
exported numbered image. A complete identity includes the source hash
and instance ID. Repeated types are distinct instances.

Visual tasks provide numbered images without answer-bearing source
attributes. Source-data tasks explicitly provide coordinates, coverage
or author-step records. Graph tasks reason about identified connector
evidence. Scene-edit tasks execute public preconditions and preserve
source poses. All JSON output keys are in English.

\section{Audit Interpretation}
Coverage is the fraction of instances whose types have a connector
definition. It is not the fraction that is physically connected.
Components belong to a partial recognized graph. A source scene can
contain several independent objects. The absence of a recognized edge
is not proof of a floating part.

The inset-mesh audit reports \LDrawIntersections{} intersection candidates
without a recognized mating interface. They remain unresolved review
items. Friction-fit geometry and gears can legitimately intersect a
mesh approximation. Connector inference normalizes rotations under
the upstream BrickNet implementation; rendering and collision queries
preserve original poses. No source is moved to improve an audit score.

\section{Reproduction and Review}
Run the acquisition and preparation scripts only when rebuilding source
assets. The retained-source corpus, questions and website bundles are
generated by \texttt{benchmark/suite/ldraw/release.ts}.
The independent verifier reparses MPD sources using locked dependency
files. Browser capture scripts produce real model views and numbered
visual inputs. The paper generator derives counts and tables from these
release artifacts.

Reference solutions are supplied for reviewer inspection. Public model
inputs exclude solutions; however, the development website exposes
review files and is not a hidden test server. An evaluation harness must
restrict its observations and record all tool access.
Failure decisions require a written reason. New review records use
separate storage and preserve old human feedback. Original authors and
licenses are included on each source page below.
