# BrickPlan 2.3 revision: source diversity and matched geometry

The preceding independent review left R5 open: sixteen source groups,
ten geometry pairs from three sources, and unequal fixed-part counts
limited independent replication and geometric attribution. Version 2.3
changes construction, qualification and scoring while preserving 2.2 bytes.
An independent scientific recommendation must refer to the final snapshot;
implementation and passing software checks do not constitute acceptance.

## R5 construction and evaluation changes

| Requirement | Implemented contract | Evidence |
|---|---|---|
| Broader source coverage | Freeze 100 additional OMR kits and their source-group split before geometry/task qualification; retain every exclusion | `source-plan.json`, `data/source-intake/`, `data/source-admission.json` |
| Substantive movable domains | New base admissions require at least eight registered sites and eight sites movable within the finite-capacity reachable component | `qualify_sources.py`, `audit_v23.py` |
| Correct source-to-question mapping | Check every active profile against original source indices, instance IDs, part/color identities, transforms, locked mesh/dependency hashes and freshly parsed connector graphs | `data/source-question-audit.json` |
| Equal-count/type contrasts | Both original fixed-instance subsets retain exactly the same total count and part-number/color multiset; no replacement or repositioning | `qualify_contrasts.py`, `data/geometry-contrasts.json` |
| Controlled task inputs | Registered instances and poses, start, goal, capacity, jobs and proposed plan remain identical; labels change only after a shared legal prefix | `diagnostics.py`, `data/source-question-audit.json` |
| Independent units and attrition | Separate source, intervention and start units; retain zero-yield qualified contexts and separate historical unequal-count regressions | `matched_metrics.py`, `data/publication-statistics.json` |
| Exact pair scoring | Both first-conflict labels must match; a missing partner, invalid response or incorrect conflict position receives zero joint credit | `evaluate.py`, `test_matched_metrics.py` |
| Explicit shortcuts and uncertainty | Publish count, inventory presence/multiset, sequence and metadata information ceilings, label-free inventory rules, development-fitted source majority, whole-source bootstrap and leave-one-source-out sensitivity | `data/matched-controls.json` |

Equal reduced inputs with different labels preclude perfect joint accuracy
for a deterministic predictor restricted to those inputs. This is an
information bound on the specified representation, not a visual-model
measurement or a claim that every possible shortcut has been eliminated.
Exact inventory controls are privileged perception abstractions.

The independent source audit excludes six preliminarily geometry-qualified
candidates: five with omitted direct model geometry and one with a conflicting
original root kit identifier. Their original files, failure proofs and earlier
admissions remain archived. These are post-qualification provenance corrections,
with no replacement candidates and no selection by policy performance.

## Retained prior repairs

R1 retains four supplied static views and separately charged active
acquisition, with native pair-specific observation certificates. R2 keeps
all-correct choices in calibration and preserves valid ties. R3 reports
inverse-solvable, inverse-suboptimal and inverse-unavailable repair cohorts.
R4 retains shallow privileged controls and interprets D1–D4 as operation
length, without asserting necessary cognitive depth.

R6 preserves acquired-frame IDs based only on public revision and view,
with metadata noninterference, replay, restart and retry regression tests.
P1 retains identifiable repair-piece callouts and exact replay costs.
The main geometry illustration is selected from a newly admitted held-out
source with a certified revealing supplied view; its caption records the
actual inventory, public actions and exact answers.

## Evidence boundary

Every released question and oracle table is checked by archived independent
transition/cost/answer rules. Source geometry qualification and observation
mapping are separate layers. Connected stud support and prescribed motion
do not establish force balance, clutch strength, arbitrary grasp access,
physical rack transfers or human answerability.

The English manuscript, supplement, original-geometry figures, workbench,
Overleaf source and runtime packages are versioned together. The official
CVPR author-kit files remain unchanged. The historical four-call SmolVLM
trace retains its original 2.1 inputs, images and failed-format outputs.
Population model and human results remain unmeasured.
