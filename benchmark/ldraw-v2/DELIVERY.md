## 主要修正

1. 数值选项不再固定把正确答案放在第二小的位置。步骤题在合法范围内平衡语义秩。
   图删除题有 63/73 个答案位于合法上界，无法同时保留答案、提供四个合法不同数值、
   并消除极值位置线索，因此改为整数响应。全部原图与语义答案保留。
2. `references` 及答案、内部证据、目标元数据不进入真实模型请求。
   图像以实际发送字节保存；评分 bundle 由路径与角色检查隔离。
3. 接口题固定提供五类选项，移除旧版选项数量透露答案的额外线索。
4. 明确区分视觉识别、源记录读取、图运算、显示编辑。`Integrative` 改为 `graph-internal`。
5. 将 24 道固定语义答案题和 17 道相同六步程序题标为控制项。
   图删除题 60.27% 的答案为 4，仍明确报告，不把这些先验当成模型能力结果。
6. 新增完整场景、同相机隐藏背景、操作数裁剪等配对条件。
   修正旧方案对标准图片、图边条件、选项置换及 ID 置换适用范围的描述。
7. 论文、表格、图像来源、每题答案与代码自动对齐。九张实验表的 264 个结果单元格保持空白/null。

保留 24 个原始套装、15,334 个零件实例、617 道题及 11 个任务族。
响应格式为 396 单选、73 多选、73 整数、75 动作题。
D1–D4 仍是源模型规模分层，未改称经过标定的认知难度。

- 阶段台账：`benchmark/ldraw-v2/UPGRADE_STATUS.md`
- 网站文档下载目录：`public/benchmark/ldraw-v2/docs/`

如服务器停止，在仓库根目录运行：

```sh
python3 benchmark/suite/ldraw-v2/serve.py --port 5175
```

生产页面通过独立构建目录 `dist-ldraw-v2` 和仓库 `public` 资产共同提供，
不能只拷贝前端构建目录就期待完整几何可用。旧版入口和原始几何没有被覆盖。

审核页支持旋转、缩放、指定视角、按 B 编号单件隔离、题目操作数隔离、
展开、作者步骤播放、动作回放与答案检查。题目和交叠候选均可按唯一 ID 访问。
反馈要求审核人、结论、理由和时间；导入时验证版本、源哈希、内容哈希与操作数。
不同审核人的意见独立保存，同一审核人的冲突意见不会被静默覆盖。
反馈保存在浏览器本地，需导出 JSON 后用于集中修正，不会自动改写题集。

## 尚未解决与不得升级的主张

1. **真实人工审核未完成。** 140 道视觉题需逐题核查编号、颜色和近同型歧义；
   另有 111 道规则命中的非视觉题。机器一致性不等于可感知性认证。
2. **573 对物理交叠候选未裁决。** 它们并非 573 个已确认缺陷，也不能据此宣称模型
   全部物理有效。重力、接触力、载荷、插入路径的真实性仍未验证。
3. **模型实验尚未运行。** 候选 adapter 可用性未向供应商实测；移动模型别名在运行前
   必须冻结真实版本。没有新排行榜，没有把旧 pilot 分数迁入新版。
4. **诊断定位与跨模块推理未验证。** 本版是单题单契约的模块化评估，
   尚未实现目标模块故障、非目标稳定性及证据恢复的完整实证。
5. **题集仍有能力上限。** 控制题较简单，局部图仅 5–9 个节点、2–6 条唯一边，
   源数量和分布有限，固定程序与答案集中度仍存在。不能把源模型大解释为题目难。

因此，回答“是否全面修改好”：**指导文件要求的自动化修整与同步已完成；
完整科学认证和物理认证尚未完成。** 后续应通过已交付的审核工作台导出真实反馈，
再据此进行版本化集中修正，并单独开展模型与诊断效度实验。

本次变更交付于本地工作区；未创建远端提交或发布站点。
