# 复杂题目示例：CX1–CX3

三道复合题来自真实 LDraw 子装配，包含完整输入、算法 GT 和原始位姿的 3D 图。
它们是本次新增的题目设计示例，尚未进行真人审核或模型采集，
不计入 display-v3 的 140 对视觉题，也不改变已有实验分母。

| ID | 题目 | 真实来源 | 推理要求 |
|---|---|---|---|
| CX1 | 多处缺失下的最小修复 | 42004 后铲，36 零件、44 条已识别连接 | 8 个缺失候选，连接 4 个终端；找全部最优集合、最终分量、判断预算是否足够 |
| CX2 | 预算约束下的自适应诊断 | 同一后铲的连接图 | 4 个三处故障世界、3 种查询；设计最坏成本最小的条件决策树 |
| CX3 | 重复轴组件匹配与位姿恢复 | 42061 的两套 12 零件轴组件 | 同型干扰下匹配 4 对锚点，恢复旋转/平移，计算探针的位置和方向 |

## GT 与验证

- **CX1**：唯一最优集合是 `{B0160, B0175, B0177}`，成本 3；预算 2 不可行。
  最终 31 个可用顶点位于同一分量。保存全部 256 个恢复子集的结果，
  另用独立并查集实现复算。
- **CX2**：先 Q3；返回 no 后查询 Q1，返回 yes 后查询 Q2。
  最坏成本 2，一次二元查询不足以区分四个世界。
  穷举 27 种两层查询方案，并核对决策树在全部四个世界的结果。
- **CX3**：`R = diag(-1, 1, -1)`，`t = (16, 0, 120) mm`。
  B0030 映射到 `(-27.9924, 24.8, -0.4212) mm`，
  局部 x 轴映射到 `(0.99938684, 0, 0.03501355)`。
  用坐标基求逆独立验证生成器的 SVD 拟合，并检查全部 12 个源零件变换。
  其他三种同型匹配的距离差超过误差容许量，排除任意合格刚体拟合。

复杂性由题目的组合约束定义，不以大型模型外观代替推理难度。
这三道题也不能用于模型排名或声称已经建立了大规模复杂任务 benchmark。

## 文件与复算

| 文件 | 用途 |
|---|---|
| [public.json](public.json) | 英文题目、完整图/故障集合/坐标输入、回答格式，不含 GT |
| [gold.json](gold.json) | GT、全部恢复子集、诊断结果表、几何拟合及验证证书 |

| [verify.py](verify.py) | 不导入生成器的独立验证 |

| [论文图](../../paper/README.md) | 三道题的 PDF/PNG、完整附录与构建说明 |

```sh
python3 -m pip install -r paper/requirements.txt
python3 benchmark/complex-examples-v1/build.py
python3 benchmark/complex-examples-v1/verify.py
```

- `http://127.0.0.1:5173/paper/complex-render.html?model=omr-42061`

选择完整模型或子装配，点击 **Render source view**。
题目图使用真实源网格及保存的位姿，不移动零件拼造效果。
CX1、CX2 的缺失是给定图上的顶点不可用状态；源图保持完整，
不把图删除画成物理拔出，也不声称已验证承载力、插入路径或重力稳定性。
连接记录来自现有审计，不能把未识别的连接当作物理上不存在。
