# BrickAtlas 多任务 Benchmark 实施计划

## 定位与边界

目标：可复现的结构数据集、八类任务、确定性指标、LLM/MLLM 单次提交基线、
独立的工具辅助赛道、训练数据导出、可浏览和重放的结果。
不涉及机器人、机械手、VLA、抓取控制。只新增/修改 benchmark/。
保留 CARE-mini v1 原始代码与结果，新系统在 suite/，不以旧任务约束新任务。

## 八个任务族

1. parts：孤立零件图像 -> 型号、颜色和可用顶部stud数。目录公开。
2. relations：完整结构程序 -> 指定两砖是否直接连接、是否有上下关系、连通分量数。
3. reconstruct：BOM + 多视图/明确披露的逐层图像 -> 完整结构。不是不可辨识的单张图猜内部。
4. generate：文字与机器可核查的空间占用约束 -> 任一合法结构。目标体积相同允许不同拆砖方案。
5. complete：部分结构 + 目标多视图 -> 完整结构，保留已给部分。
6. edit：结构 + 明确修改指令 -> 修改后结构，非目标部分保持不变。
7. plan：完整目标 -> 任一合法装配或拆解顺序；按声明的垂直插入/移除规则验证每一步。
8. repair：受控损坏结构 + 目标多视图 -> 正确结构与错误实例定位，含无故障负例。

## 统一结构协议

毫米映射：X/Z=stud(8mm)，Y=plate(3.2mm)，整数网格，yaw取0/90/180/270。
节点包括id、partId、color、x/y/z、turn；边由真实网格stud交叠导出，含接触stud数量。
除坐标数组外，提供父子相对位置程序作为可逆替代表达；明确它不是完整 BrickNet 端口语言。
上下游统一decode再评分，不按字符串顺序或实例ID判等。
未知目录、非法字段、NaN/Infinity、重复ID、重叠体、无支撑、额外零件均显式处理。

## 数据策略

- 先交付程序化、带证书、可扩展的多个结构族；模板/几何组与颜色变体分别统计。
- train/validation/test_id 在几何组级隔离；test_ood 为整类结构留出，不承诺未知真实世界类别泛化。
- 结构signature归一化平移和四种yaw并忽略颜色，跨split审计。
- 派生八任务、render、caption和答案继承父模型split，不单独随机切分。
- 数据生成器、seed和sha256固定。公开研究开发集不是防污染的私有leaderboard。
- 既有15个OMR资产只读盘点、保留原许可，不把未验证的任意LDraw连接伪装为规则砖连接。

## 模型与训练

主榜 one-shot：固定输入 -> 一次输出 -> 裁判；没有错误位置提示或自动修正。
辅助榜 validator-once：最多一次仅合法性反馈后重新提交；不给真值差分，单列成本。
旧 CARE-mini 是交互 agent 环境，不与主榜合并。
LLM可跑结构/文本任务；MLLM可跑图像任务；图像移除或答案坐标输入必须另标条件。
支持本地/外部模型 predictions.jsonl 的独立评分，不锁定 OpenRouter。
导出仅 train 的SFT消息/答案与本地图像引用；验证split独立；不声称仅导出就训练了权重。
神经模型微调需要后续明确算力和训练实验，本轮先以真实API基线打通全部模型流程。

## 初步指标

- 分任务格式成功率、目标达成率、所有请求的成功率（含格式失败；网络失败另列）。
- 几何/零件任务：BOM F1、对称性aware Part F1、连接Edge F1、占用IoU、状态合法率。
- 生成任务：合法率+约束满足（不是CLIP语义理解；当前为受控描述），不强迫唯一拆砖。
- 编辑/补全：目标正确性、源结构保留；修复同时报告定位F1和目标恢复。
- 规划：完整性、合法动作比例、前缀完成率、结束状态；无机械臂可达性宣称。
- 独立报告 n、宏平均/各任务值、Wilson描述区间、tokens、耗时与实际费用。
- 对模型、输入信息、输出表示、辅助预算分别分组；缺席任务不能当满分参与平均。

## 成本与验收实验

沿用旧campaign的4.50美元硬预算（历史已花约0.11美元），不重置账本。
第一轮固定每任务少量test_id/test_ood样本、两个视觉模型；禁止全量付费评测。
oracle全量自测是评分器验证，不作为模型成绩；空输出/复制输入为低阶对照。
人工挑选样例仅用于开发，正式抽样名单必须在请求前落盘并hash冻结。
